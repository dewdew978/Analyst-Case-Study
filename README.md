# FruitBlend24 วิเคราะห์ยอดขายและกำไร

วิเคราะห์ยอดขาย ก.ย. 2025–ส.ค. 2026 เพื่อประเมินราคา โปรโมชัน กำไรแต่ละครัว และวางแผนวัตถุดิบกับ P&L ล่วงหน้า 3 เดือน นำเสนอผ่าน Streamlit

อ่าน **5 Key insights ข้อเสนอทางธุรกิจ วิธีวิเคราะห์ สมมติฐาน และสิ่งที่อยากศึกษาต่อ** ได้ใน [REPORT.md](REPORT.md)

## เปิดใช้งาน

1. เปิด Terminal ในโฟลเดอร์งาน แล้วติดตั้งด้วย `python -m pip install -r requirements.txt`
2. เปิด `analysis.ipynb` แล้วกด **Run All** เพื่อสร้างข้อมูลและผลวิเคราะห์
3. เปิดแอปด้วย `python -m streamlit run app.py`

โครงการมี CSV พร้อมใช้งานอยู่แล้ว หากต้องการดูแอปอย่างเดียว สามารถข้ามขั้นตอนที่ 2 ได้

ลำดับข้อมูล: **Excel → Notebook คลีน → cleaned_data → Notebook วิเคราะห์ → app_data → Streamlit**

Notebook บันทึก CSV ไว้ท้ายหัวข้อที่คำนวณตารางนั้น: ข้อ 2 ยอดรายชั่วโมง, ข้อ 3 โปร/แพลตฟอร์ม, ข้อ 4 P&L/ครัว/เมนู/กะดึกและผลเทียบแถวซ้ำ และข้อ 5 พยากรณ์/วัตถุดิบ/ข้อมูลรอบพยากรณ์และ stress test

เมื่อมี `cleaned_data/` ครบแล้ว สามารถ Restart Kernel และเริ่มรัน Notebook จากหัวข้อ 2 ได้ หากข้อมูลต้นฉบับหรือวิธีคลีนเปลี่ยน ให้ Run All ใหม่ หากแก้เฉพาะวิธีวิเคราะห์ ให้รันจากหัวข้อ 2 แล้วรีเฟรชแอป

ใช้ Python, pandas, NumPy, openpyxl, Plotly และ Streamlit รายละเอียดวิธีที่ใช้ในแต่ละขั้นตอนอยู่ในรายงาน

ดูผลเทียบแถวซ้ำได้ใน `app_data/duplicate_sensitivity.csv` และ stress test 18 กรณีใน `app_data/scenario_sensitivity.csv` ตารางสั่งซื้ออ้างกรณีฐาน ส่วนกรณีลดของเสียและประหยัดค่าใช้จ่ายเป็นเงื่อนไขที่ยังต้องทดสอบ

ตารางแพลตฟอร์มอยู่ใน `app_data/platform_performance.csv` และกะดึกอยู่ใน `app_data/night_shift.csv` ทั้งสองเป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่ผลประหยัดที่ยืนยันแล้ว
